# Security policy

Astral Arena does not currently expose a network service. Do not add a public Eddard tunnel route or accept community snapshots until the coordinator has authentication, request limits, schema validation, UUID allowlists, quarantine, and audit logging described in `docs/EDDARD_COORDINATOR.md`.

Report vulnerabilities privately through GitHub's security-advisory feature once it is enabled for the repository. Do not include access tokens, Cloudflare credentials, save files, or private server configuration in a public issue.
