# Terrain playtest — November 5, 2026

Candidate: **0.6.0-alpha.2**, module build 25. Toolkit 4.1.1.6931813,
MoonGlasses 1.3.0.586, BG3 DirectX 11 with Script Extender.

## Method

Created a fresh Balanced Adventure with a custom barbarian named AA Terrain
Test, completed native level-up to level 3 and saved a separate checkpoint.
Existing campaigns were not loaded or overwritten. Confirmed one game process;
the Script Extender console is a second window of that same process. The Toolkit
was closed while the game ran. Observed around 120 FPS in the arena.

A temporary package substituted an earlier version of
`tools/playtest/terrain_probe.lua` for the server bootstrap. It disabled normal
onboarding/combat prompts, checked the disposable checkpoint's level and starting
position, and placed the character beside a
stair. It then records positions once per second. Walking tests use native mouse
clicks, with no movement scripts or teleport fallback. Explicit setup teleports
are separately recorded. This probe is excluded from the normal release PAK.

## Terrain iterations

- Original alpha.1: native walking climbed the north stairs to y=2.076 m, then
  stopped where the platform overlapped the approach. See
  [first-pass positions](playtests/terrain-navigation-2026-11-05.json).
- First alpha.2 trial: moved both platforms 3 m outward and rebaked. Walking
  reached y=2.770 m, but a visible gap prevented entering the landing.
- Corrected both landings to z=-43.5 and z=-76.5, retaining y=3 and the mirrored
  stair rotations. Ran Full Generate and AI Grid Save again; a native click still
  stopped below the landing on the existing checkpoint.
- Lowered both platforms to y=2.7 and rebaked. The final Toolkit output has
  147,620 cells, 4,346 bytes and SHA256
  `622c9075f66f5412429bd0dceb93b9184e481004aaee787d1af579b895402ae6`.
- Inspection then found the checkpoint's embedded grid still has the original
  147,548 cells (`AiGridDefinition.Size=295096`, two bytes per cell). Subsequent
  tests had loaded an old saved grid while showing new scenery. They cannot
  establish whether the replacement bake connects the landings correctly.
- Fresh-Adventure retesting was prepared but not run. On November 6 the user
  requested coding work without further playtests. The normal package was
  restored. Final platform traversal remains unverified.

## Other observations

- AA_Arena_Main loads after fresh character creation.
- One Astral Flats rock blocked a click into its footprint; a click across it
  routed the character around it. This is a spot check, not validation of every
  tactical piece or ranged line of sight.
- Stairs render as recognizable, character-scale stairs. The north and south
  assets are authored with opposite rotations; both still require full traversal
  in a fresh Adventure using the final bake.
- The arena ground is brown rather than uniformly grey. Stonework, vegetation
  and banners are visible. Oversized perimeter/backdrop assets obscure the camera
  in staging, the sky is empty blue and the minimap is black. Visual polish fails.
- The Withers ledger and ready prompt still show raw localization handles.
  Packaged localization alone did not resolve the defect in the real game.
- Ready reminders can interrupt menus every minute. The terrain probe avoids
  them; the normal controller still needs a usability fix.

## Release limits

148 Lua tests, the engine smoke simulation, Toolkit project validation and all
156 spawn geometry checks pass. Those checks use fake game APIs where applicable.
Enemy engagement at 45–49 m, total-party-wipe recovery and ten consecutive full
3 → 5 → 8 → 10 → 12 runs remain unverified in the real game. No main-branch merge
or release-ready claim is justified by this terrain test.
